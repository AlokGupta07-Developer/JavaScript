# JavaScript Functions – Overview

### 1. Normal Function
A function is a reusable block of code designed to perform a specific task. It executes when it is called.

### 2. Anonymous Function
A function without a name is called an anonymous function. It is commonly assigned to a variable or passed as an argument.

### 3. Arrow Function
An arrow function is a shorter syntax for writing functions in JavaScript. It uses the `=>` operator.

### 4. First-Class Function
JavaScript treats functions as values, allowing them to be stored in variables, passed as arguments, and returned from other functions.

### 5. Callback Function
A callback is a function passed as an argument to another function. It is executed by that function when required.

### 6. Higher-Order Function (HOF)
A higher-order function is a function that accepts another function as an argument or returns a function.

### 7. Recursive Function
A recursive function is a function that calls itself to solve a problem. It requires a base condition to stop execution.

### 8. Pure Function
A pure function always returns the same output for the same input and does not modify external data or cause side effects.

### 9. Impure Function
An impure function depends on or modifies external data and may produce different results due to external state or side effects.

### 10. Closure
A closure is created when an inner function remembers and accesses variables from its outer lexical scope, even after the outer function finishes.

### 11. Lexical Scoping
Lexical scoping means a function accesses variables based on where it is defined in the source code, following its scope chain.

### 12. IIFE (Immediately Invoked Function Expression)
An IIFE is a function expression that executes immediately after it is defined, without requiring a separate function call.
