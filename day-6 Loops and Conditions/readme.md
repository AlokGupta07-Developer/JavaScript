# JavaScript Day 6 – Loops & Control Flow

## 1. Control Flow

Control flow determines the order in which JavaScript statements are executed.

### Types of Control Flow

- `if`
- `if-else`
- `else-if`
- `switch`
- Ternary Operator

## 2. Loops

Loops are used to execute a block of code repeatedly.

### Types of Loops

- `for` Loop
- `while` Loop
- `do-while` Loop
- `for...in` Loop
- `for...of` Loop

## 3. Loop Control Statements

- `break` – Terminates the loop.
- `continue` – Skips the current iteration.
- `return` – Exits a function and returns a value.

## 4. Key Points

- Control flow manages program execution.
- Conditions help make decisions.
- Loops reduce repetitive code.
- `break` stops loop execution.
- `continue` skips an iteration.
