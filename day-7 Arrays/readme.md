## 3. Basic Array Methods

- `push()` – Adds an element at the end.
- `pop()` – Removes the last element.
- `unshift()` – Adds an element at the beginning.
- `shift()` – Removes the first element.
- `length` – Returns the number of elements.

## 4. Searching Methods

- `indexOf()` – Returns the first index of an element.
- `lastIndexOf()` – Returns the last index of an element.
- `includes()` – Checks whether an element exists.
- `find()` – Returns the first matching element.
- `findIndex()` – Returns the index of the first matching element.
- `findLast()` – Returns the last matching element.
- `findLastIndex()` – Returns the index of the last matching element.

## 5. Modification Methods

- `splice()` – Adds, removes, or replaces elements.
- `slice()` – Returns a portion of an array.
- `concat()` – Combines two or more arrays.
- `fill()` – Fills elements with a specified value.
- `copyWithin()` – Copies array elements within the same array.
- `toSpliced()` – Returns a modified copy without changing the original array.
- `with()` – Returns a copy with an element replaced.

## 6. Iteration Methods

- `forEach()` – Executes a function for each element.
- `map()` – Creates a new array by transforming elements.
- `filter()` – Creates a new array with matching elements.
- `reduce()` – Reduces an array to a single value.
- `reduceRight()` – Reduces an array from right to left.
- `flatMap()` – Maps elements and flattens the result.

## 7. Sorting Methods

- `sort()` – Sorts array elements.
- `reverse()` – Reverses array elements.
- `toSorted()` – Returns a sorted copy.
- `toReversed()` – Returns a reversed copy.

## 8. Checking Methods

- `every()` – Checks whether all elements satisfy a condition.
- `some()` – Checks whether at least one element satisfies a condition.

## 9. Conversion Methods

- `join()` – Converts array elements into a string.
- `toString()` – Converts an array into a string.
- `toLocaleString()` – Returns a localized string representation.
- `flat()` – Flattens nested arrays.

## 10. Static Array Methods

- `Array.isArray()` – Checks whether a value is an array.
- `Array.from()` – Creates an array from an iterable or array-like object.
- `Array.of()` – Creates an array from given arguments.

## 11. Other Methods

- `at()` – Returns an element using a positive or negative index.
- `keys()` – Returns an iterator of array indexes.
- `values()` – Returns an iterator of array values.
- `entries()` – Returns an iterator of index-value pairs.
- `Symbol.iterator` – Provides the default array iterator.

## 12. Key Points

- Arrays use zero-based indexing.
- Arrays can store different data types.
- `push()` and `pop()` modify the original array.
- `map()` and `filter()` return new arrays.
- `reduce()` returns a single accumulated value.
- `slice()` does not modify the original array.
- `splice()` modifies the original array.
- `sort()` sorts elements as strings by default.
